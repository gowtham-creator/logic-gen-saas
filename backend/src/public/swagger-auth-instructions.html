🔐 API Documentation Access

To use the API documentation, you need to authenticate with a JWT token.

1 Get Your JWT Token

Log in to the application and obtain your JWT token from the authentication response, or use the login endpoint:

POST /api/auth/login
2 Open Swagger UI

Navigate to the API documentation page.

3 Click "Authorize" Button

In the Swagger UI, click the green "Authorize" button at the top of the page.

4 Enter Your Token

In the authorization dialog:

  • For Bearer Auth: Enter your JWT token (without the "Bearer " prefix)
  • For API Key Auth: Enter your API key in the X-API-Key field

Click "Authorize" and then "Close".

5 Use the API

Now you can use "Try it out" on any endpoint. Your token will be automatically included in requests.

Go to API Documentation →
Note: Your authentication token will be stored in your browser's local storage. Make sure to log out or clear your browser data when using a shared computer.
